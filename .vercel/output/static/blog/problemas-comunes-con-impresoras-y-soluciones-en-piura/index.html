Causas comunes:

  • Controladores desactualizados
  • Conexiones USB/Wi-Fi defectuosas
  • Cola de impresión bloqueada
  • Configuración incorrecta de red

Solución ESVA:

El 70% de estos casos se resuelven con mantenimiento preventivo de drivers y actualizaciones de firmware” - Técnico Senior ESVA.

  3. Actualiza controladores desde sitio oficial
  4. Llama a soporte técnico si persiste el error
